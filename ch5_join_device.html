第 5 章

加入第一個裝置

讓一台裝置的 tailscale client 指向你的 Headscale，並用它加入網段。讀完這章，你的第一台裝置會出現在節點清單裡，私有網段正式開張。

網段要有裝置才算活起來

第 4 章建好了 user 與 preauth key，但網段裡還沒有任何裝置。這章讓第一台裝置加入，驗證整條「控制層 → 金鑰 → client」的流程真的通了，之後每台裝置都照同樣做法。

本章任務：在裝置裝 tailscale client、指向 Headscale、用 key 加入，並確認節點出現在清單裡。

裝置怎麼加入網段

裝置上的 tailscale client 預設連官方伺服器；要連你的 Headscale，得告訴它「控制層在哪」。做法是在 tailscale up 時加上 --login-server 指向你的 Headscale 網址。

步驟說明
裝 client在裝置安裝 tailscale（官方 client）
指向控制層tailscale up --login-server <網址>
授權貼上 preauth key，或走瀏覽器登入
驗證在 Headscale 看節點出現
關鍵差異：官方 Tailscale 用 tailscale up 直接登官方；自架只要多補 --login-server 這一項，其餘體驗一樣。

六步加入第一台裝置

  1. 在裝置裝 tailscale client

    到 Tailscale 官網下載對應作業系統的 client 並安裝（Windows、macOS、Linux、iOS、Android 皆有）。

  2. 準備好 preauth key

    拿出第 4 章產生、還沒用掉的 preauth key。

  3. 指向 Headscale 並登入

    在終端執行 tailscale up --login-server <Headscale 網址>，例如 tailscale up --login-server https://你的網址。

  4. 用 key 授權

    依提示貼上 preauth key；或走瀏覽器授權流程登入。

  5. 等待連線建立

    client 會連上控制層、取得節點身份，跑完 tailscale up 即完成。

  6. 回 Headscale 驗證

    執行 headscale nodes list，看到新節點出現在清單，代表加入成功。

網址要對：--login-server 要填你的 Headscale 對外網址（含 https）。填錯會連去錯誤的控制層或直接失敗。

各作業系統的差異

平台加入方式注意
Windows／macOS／Linux終端 tailscale up --login-server ...Linux 常無頭部屬，適合用 preauth key
iOS／AndroidApp 內設定自訂控制層網址再登入App 有「使用自訂伺服器」選項，填 Headscale 網址
server 常駐：Linux 上可用 tailscale up 後讓 client 常駐（依發行版用 systemd 等），之後開機自動連上。

驗證加入成功

  • 在裝置執行 tailscale status，應顯示已連線與分配的節點位址。
  • 在 Headscale 執行 headscale nodes list，確認新節點與它隸屬的 user 正確。
  • 加第二台裝置後，兩台之間應能互相 ping 通（第 6、7 章會講互連與 ACL）。

加入常見卡關

  1. --login-server 連不上

    確認網址完整、含 https、對外可達；用瀏覽器開同網址測試（Headscale 控制層未必有網頁，但能確認 DNS 與憑證）。

  2. key 被拒

    key 可能過期、用過（一次性）、或綁錯 user。重新產生一把。

  3. client 已連過官方帳號

    先 tailscale logout 登出官方，再重新 tailscale up --login-server ...。

  4. nodes list 沒看到

    稍等幾秒讓 client 完成註冊；仍沒有就回裝置看 tailscale status 的錯誤訊息。

加入常見問題

一定要用 preauth key 嗎？
不一定。也可以走互動式登入（瀏覽器授權）。preauth key 適合無頭裝置或自動化，互動登入適合有畫面的裝置。
一台裝置能同時連官方和 Headscale 嗎？
同一時間通常只連一個控制層。要切換就先 tailscale logout 再連另一個。
加入後裝置有固定位址嗎？
會分配一個網段內的位址，通常穩定但不保證永久不變。對外辨識用節點名稱較可靠。
手機 App 怎麼連自架？
App 登入頁通常有「自訂伺服器／use custom server」選項，填入你的 Headscale 網址即可。
加入後還沒互連？
預設 ACL 可能尚未放行互連，這是第 7 章要講的存取控制，先確認節點都已上線。
