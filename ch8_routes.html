路由與出口節點

用 subnet router 把整段內網帶進你的私有網段，用 exit node 讓流量從某個裝置出去。讀完這章，你能在家裡以外的網路，安全存取家裡的 NAS、印表機等整個內網。

不只是連裝置，還能把整段內網帶回家

前面幾章連的是「單一裝置」。但家裡往往有一整段內網（NAS、印表機、監視器、路由器），它們不一定能裝 tailscale。用 subnet router，你可以指定一台裝置當「橋」，把整段內網都接進私有網段。

本章任務：了解 subnet router 與 exit node 的差別，學會宣告與啟用路由。路由設定會影響整個網段，操作前先確認範圍。

subnet router 與 exit node

概念做什麼典型用途
subnet router把某段內網（如 192.168.1.0/24）接進網段，讓其他節點能存取該內網的裝置在外存取家裡的 NAS、印表機
exit node讓其他節點的「所有對外流量」從這台出去在咖啡廳用家裡的 IP 上網、加密對外連線
兩者不同：subnet router 是「把內網帶進來」；exit node 是「把流量送出去」。別搞混。

六步設定 subnet router

  1. 選一台常開機的裝置當橋

    選一台在家裡、會一直開機的裝置（例如 Home Assistant 主機、NAS）當 subnet router。

  2. 宣告要轉送的內網

    在該裝置執行 tailscale up --advertise-routes=192.168.1.0/24（換成你家的網段）。

  3. 在控制層核准路由

    用 Headscale 的 route 命令查看並啟用這個 subnet 路由，否則不會生效。

  4. 其他裝置測試連內網

    從另一個節點 ping 內網裝置（如 ping 192.168.1.10），確認能通。

  5. 需要時設 exit node

    在橋接裝置加 --advertise-exit-node，其他節點再指定用它當出口。

  6. 盤點並最小化

    只宣告真正需要的網段，別把整個大網段全開出去。

最小暴露：宣告的網段越寬，能碰到的東西越多。只開需要的那一小段（例如 NAS 所在的子網），不要整段內網全開。

出口節點（exit node）

exit node 讓你的裝置把「所有對外流量」都走某一台節點出去。這在「人在外面、想要用家裡的 IP 上網」或「加密公共 Wi-Fi 的對外連線」時很有用。

  • 設定後，其他節點要「手動選擇」這台當 exit node 才會生效。
  • 注意：所有流量都經過它，出口那台的頻寬與位置會影響速度。
  • 用它當「翻牆回家」的工具時，務必遵守當地的服務條款。
exit node 不是萬能代理：它只是把你的出口改到別處，不改變內容加密或隱私的基礎原則。

路由常見卡關

  1. 宣告了但內網連不上

    確認控制層已「啟用」該 route（宣告不等於啟用）；確認網段寫對。

  2. 能 ping 到 router 但 ping 不到內網

    檢查 router 那台是否開啟 IP 轉送（IP forwarding）；不同 OS 設定不同。

  3. exit node 沒生效

    其他節點要「手動選」這台當 exit node；確認這台有宣告 exit node 且控制層已接受。

  4. 內網裝置不會回包

    內網裝置的防火牆或預設閘道可能擋來自 tailscale 網段的流量，檢查內網路由。

路由常見問題

subnet router 那台一定要一直開機嗎？
要。它是「橋」，關了就斷。選一台穩定、常開機的裝置。
一次能宣告多個網段嗎？
能，逗號分隔多個 --advertise-routes 網段。但記得最小化，只開需要的。
exit node 和 VPN 一樣嗎？
效果類似「把出口改到別處」，但它是 Tailscale/Headscale 網狀架構的一環，不是傳統集中式 VPN。
宣告路由有安全風險嗎？
有，等於把該網段曝露給網段內其他節點。務必搭配 ACL 限制誰能連，且只開最小網段。
手機能當 subnet router 嗎？
理論上可以，但不建議（手機常休眠、IP 轉送支援有限）。用常開機的裝置較穩。
