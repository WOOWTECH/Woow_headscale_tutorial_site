Headscale Resource Hub

Four handbooks for a self-hosted VPN control server, all in one place: how to use it, how to sell it, how to drive it from the CLI and how to add new skills. Three of them download as a single HTML file, so you can save one and read it offline.

The four handbooks

Onboarding tutorial

For users · 12 chapters

From installing, creating a user and a preauth key, and joining a device, all the way to node management, ACL, routes, DNS, admin settings and troubleshooting. 10 minutes per chapter.

Sales Handbook

For customers and resellers · single page

Link the household's devices into a private tailnet of your own: what Headscale can do, the two deployment options — Option A, self-hosted on your own Home Assistant host; Option B, managed by WoowTech, a day-in-the-life scenario and a side-by-side comparison, in plain language for customers.

Read online Download HTML

Prompt Library

For users · 23 copy-and-paste prompts

Not sure how to drive Headscale from the CLI or the API? Managing users and preauth keys, node inventory, ACL, routes, DNS, backups, troubleshooting — copy any prompt, paste it and adjust.

Read online Download HTML

Skill Handbook

For advanced users · catalog + quick reference

Install a skill someone else has already built, and your AI agent can manage nodes, take inventory of keys and keep the ACL and the backups in order. A selection of useful skills and ecosystem tools, with an install quick reference and security notes (surveyed 2026-08).
