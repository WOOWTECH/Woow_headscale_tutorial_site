Chapter 2

Install Headscale

Install the Headscale control server into Home Assistant and learn what state it is in right after the install. By the end of this chapter, you'll know what an add-on is, what it is busy doing while it starts, and what to check before you open it for the first time.

Get the control server running first

Headscale is the brain of the whole tailnet. It has to be installed and running before you can create users, join devices or set up an ACL. On Home Assistant (HA), the simplest way is to install it as an add-on, so you do not have to build a server, a database and certificates yourself.

This chapter gets the add-on installed and started, and explains what it is doing in the background on that first start, so you do not conclude that it "will not start" when it is only still initializing.

Chapter task: Add the repository, install the add-on, start it, and confirm the status is normal. Creating users for real starts in Chapter 4.

What an add-on is and what it saves you

Think of an add-on as a "one-click service bundle". Headscale itself needs a database, a config file, an externally reachable port and so on; the add-on packages all of that into one container. All you do is press install, and it prepares everything that needs preparing.

What you skipWhat the add-on handles
Installing a database and dependenciesAlready packaged inside the container
Writing a config file and generating keysThe first start initializes them automatically
Handling inbound connectionsWorks with Cloudflare Tunnel (this site's setup) for secure access from outside
This site's setup: The machine you are going to use has already been installed and started by WoowTech. If you only need to use it, you can skip the install and go straight to Chapter 3 to get to know the control interface.

Six steps to install Headscale

  1. Open the HA add-on store

    In the Home Assistant sidebar, go to "Settings → Add-ons" and open the add-on store.

  2. Add the WoowTech repository

    In the store's top-right menu, choose "Repositories", paste in the WoowTech repository URL and add it.

  3. Find the Headscale add-on and install it

    Refresh the store, find Headscale, open it and press "Install". The first install downloads the image, which takes a few minutes; do not close it partway through.

  4. Review the configuration options

    After the install, open the "Configuration" tab and check options such as the data directory and the external domain. The defaults are fine the first time; adjust them later as you need to.

  5. Start the add-on

    Go back to the "Info" tab and press "Start". The first start initializes the database and generates the config and keys, so it takes a while.

  6. Check the status and the log

    Once it is started, open the "Log" tab; a message saying initialization is complete means it is ready. When the status shows as running, you can move on to Chapter 3.

First start takes a while: The first start has to build the database and generate the config and keys, which can take several minutes. As long as the log is still moving, it is working; do not keep restarting it. Note: these steps assume the WoowTech add-on repository on Home Assistant. If you run Headscale outside Home Assistant, use the official Docker or package install instead; everything after this chapter still applies.

Common install pitfalls

  1. The install just keeps spinning

    The first image download is slow by nature, so check that your network is fine and wait. If it really is stuck, look in the log for errors.

  2. It starts, then goes back to stopped

    Read the log and find the first error message (usually a config problem or a port conflict), fix it, then start it again.

  3. The log keeps reporting connection errors

    The external domain or the port is probably wrong, so check them against the configuration options; if it still fails, ask an admin for help.

  4. You cannot find the add-on

    Check that you added the repository URL correctly and refreshed the store; reload the store page if you have to.

Install FAQ

I only want to use it. Do I have to install it myself?
No. The setup on this site is already installed by WoowTech, so go straight to Chapter 3 and get to know the control interface. This chapter is for people who install it themselves.
Does the install take up much space?
Headscale itself is small; what takes up space is the database and the logs it builds up later. Check that the host has enough storage before you install.
Can I install it somewhere other than HA?
Yes. Headscale has official Docker and package install methods. This tutorial is written around the HA add-on; for the other methods, see the official documentation.
What should I do first after installing?
First confirm the add-on is running normally and that you can query the version, then create users and keys as described in Chapter 4.
Is a long start normal?
The first start has to initialize the database and the config, so anything within a few minutes is normal. If the log is still moving, do not restart it.
