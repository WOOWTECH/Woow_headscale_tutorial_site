第 2 章

安裝 Headscale

把 Headscale 控制層裝進 Home Assistant，並認識安裝後的初始狀態。讀完這章，你會知道 add-on 是什麼、啟動時在忙什麼，以及第一次開啟前該確認哪些事。

先把控制層裝起來

Headscale 是整張私有網段的「大腦」，得先裝起來、跑起來，後面才談得上建立使用者、加入裝置、設定 ACL。在 Home Assistant（HA）上，最省事的方式是透過 add-on（附加元件）安裝，不用自己弄伺服器、資料庫、憑證。

這章帶你把 add-on 裝好、啟動，並理解首次啟動時它在背景做什麼，避免你以為「怎麼開不起來」其實只是還在初始化。

本章任務：加入套件來源、安裝 add-on、啟動，並確認狀態正常。真正建立使用者從第 4 章開始。

add-on 是什麼、幫你省了什麼

add-on 可以想成「一鍵安裝的服務套裝」。Headscale 本體需要資料庫、設定檔、對外 port 等，add-on 把這些打包成一個容器，你只要按安裝，它會自動把該準備的都準備好。

你不用自己做的事add-on 幫你處理
裝資料庫與相依套件容器內已打包好
寫設定檔與產生金鑰首次啟動會自動初始化
處理對外連線搭配 Cloudflare Tunnel（本站環境）從外部安全連入
本站環境：你要用的這台已由 WoowTech 裝好、跑起來。如果只是要「使用」，可以略過安裝、直接看第 3 章認識控制介面。

六步把 Headscale 裝起來

  1. 打開 HA 的 Apps 商店

    在 Home Assistant 左側選單找到「設定 → 附加元件（Add-ons）」，進入附加元件商店。

  2. 加入 WoowTech 套件來源

    在商店右上角選單選「套件來源（Repositories）」，貼上 WoowTech 的 repository 網址並加入。

  3. 找到 Headscale add-on 並安裝

    重新整理商店，找到 Headscale，點進去按「安裝」。首次安裝會下載映像檔，需要幾分鐘，別中途關掉。

  4. 檢視設定選項

    安裝後先看「設定（Configuration）」分頁，確認資料目錄、對外網域等選項。第一次可以先用預設，之後再依需要調整。

  5. 啟動 add-on

    回到「資訊（Info）」分頁按「啟動（Start）」。第一次啟動會初始化資料庫、產生設定與金鑰，需要等一段時間。

  6. 確認狀態與日誌

    啟動後看「日誌（Log）」分頁，出現初始化完成的訊息表示就緒。狀態顯示執行中即可進入第 3 章。

初次啟動要有耐心：第一次啟動要建資料庫、產生設定與金鑰，可能要好幾分鐘。日誌還在跑就代表正常，不要反覆重啟。

值得認識的設定選項

選項說明注意
資料目錄資料庫與設定的存放位置要納入備份（附錄 B）
對外網域控制層供 client 連線用的位址要和你的對外網址一致
監聽 port控制層監聽的連接埠通常用預設即可，改錯會連不上
log 等級日誌詳細程度排錯時可暫時調高，事後調回
改設定要小心：add-on 的設定會寫進 Supervisor options，改錯可能讓控制層起不來。拿不準就用預設，或請管理員調整。

檢查項通過條件
add-on 狀態顯示「執行中」
日誌沒有反覆錯誤，出現初始化／就緒訊息
版本確認能查詢到 Headscale 版本（第 3 章）

安裝常見卡關

  1. 安裝一直轉圈

    首次下載映像檔本來就慢，確認網路正常、耐心等。真的卡住看日誌有沒有錯誤。

  2. 啟動後狀態變回停止

    看日誌找第一個錯誤訊息（多半是設定或連接埠衝突），修正後再啟動。

  3. 日誌一直報連線錯誤

    可能是對外網域或 port 沒設對，核對設定選項；仍不行請管理員協助。

  4. 找不到 add-on

    確認套件來源網址加對、商店有重新整理；必要時重開商店頁面。

安裝常見問題

我只是要用，需要自己安裝嗎？
不用。本站環境已由 WoowTech 裝好，直接看第 3 章認識控制介面即可。這章是給要自己裝的人參考。
安裝會佔很多空間嗎？
Headscale 本體不大，主要佔空間的是之後的資料庫與日誌。安裝前確認主機有足夠儲存。
可以裝在非 HA 的環境嗎？
可以，Headscale 有官方 Docker 與套件安裝方式。本教學以 HA add-on 情境為主，其他方式請參考官方文件。
安裝後要先做什麼？
先確認 add-on 正常執行、能查到版本，再依第 4 章建立使用者與金鑰。
啟動很久是正常的嗎？
第一次啟動要初始化資料庫與設定，幾分鐘內都算正常。看日誌還在動就別重啟。
